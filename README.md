# Simple Portofolio Website from Group 4

The following repository contains our website detailing information regarding our Experience and Capabilities regarding our own Chosen Majors including a Project that we have previously created according to our specific fields.

### Note: the contents of our website is displayed in Indonesian.

## 1. Website Composition
As seen through the description of the repository our website uses simple vanilla HTML, CSS and JS requires no further alterations to run.

## 2. Production Timeline
This website took approximately 4 days to create as we used a pre-existing template and modified it to fit our content, along with a few fixes regarding responsiveness. Most of the work done to realize this project was done outside of school and coordinated online.

## 3. Project Aim
Through this project we hope to prove our understanding and abilities in web development in a real world use case through a portfolio website that can be accessed whenever and wherever.
